📈 每日报表
每日下班导入 Excel → 自动生成日报 → 报表可导出
📥 每日下班导入 Excel · 自动生成每日报表 支持 .xlsx / .xls / .csv
数据来源 每日下班导入 Excel 表格 导出格式：Excel 工作簿 模板：未上传 本站未对接任何生产业务系统，报表由使用者导入的表格汇总生成

每日下班把当天通行明细 Excel 拖入下方，系统按日期自动汇总为一条日报（入区 / 出卡 / 重空 / 一线放行 / 边民申报 / 异常）， 同时自动识别「货物名称」列，按当前上传的模板口径统计车数与重量（毛重千克 ÷ 1000 = 吨）； 同一天重复导入会覆盖更新，不会产生重复数据。也可直接导入已汇总好的日报表。 若表格只有货物明细（如进出记录）、不含日报汇总列，仍会自动完成货物统计与模板报表导出，仅跳过日报生成。

📄
点击选择，或把 Excel / CSV 文件拖到这里
支持中文表头：货物名称 / 日期 / 时间 / 方向 / 重空 / 放行结果 / 边民申报 / 异常
🧩 报表模板 · 货物名称自动识别 上传你的 Excel 模板，按模板口径统计导入的明细
当前模板 尚未上传模板 0 个工作表 0 个货物项 模板只需上传一次；每日导入明细时自动识别货物名称并按模板统计

上传你自己的报表模板（如 B 卡报表）：系统自动识别「货物名称 / 车数 / 重量」列组与合计行， 再把每日导入的明细按货物名称归类、填回模板格式并导出。模板保存在云端，刷新后自动恢复。

重量口径：毛重(千克) ÷ 1000 = 吨
📦 货物名称统计 按模板清单归类 / 明细原值双视角
