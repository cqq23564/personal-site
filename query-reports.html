📥 每日下班导入 Excel · 自动生成每日报表 支持 .xlsx / .xls / .csv
数据来源 每日下班导入 Excel 表格 导出格式：Excel 工作簿 模板：未上传 本站未对接任何生产业务系统，报表由使用者导入的表格汇总生成

每日下班把当天 Excel 拖入下方，系统自动识别两种格式： ① 已汇总报表（如 B 卡报表）——直接读取表内「货物名称 / 车数 / 重量」列组与车辆验放合计，按统计日期写入日报； ② 逐车明细——按日期自动汇总为一条日报（入区 / 出卡 / 重空 / 一线放行 / 边民申报 / 异常），并自动识别「货物名称」列按模板口径统计车数与重量（毛重千克 ÷ 1000 = 吨）。 货物名称按统一口径归并：白火龙果 / 红心火龙果 / 鲜火龙果 等一律按「火龙果」合并计算车数与重量。 导入结果按统计日期归类保存在云端，下方「历史导入数据」面板可切换日期查看，刷新或换设备登录都不会丢失，数据看板首屏同步显示入区 / 出区车数与重量。 同一天重复导入会覆盖更新；若表格只有货物明细、不含日报汇总列，仍会完成货物统计与模板报表导出，仅跳过日报生成；解析不出有效数值时不会写入全 0 日报。
