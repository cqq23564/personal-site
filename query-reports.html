📈 每日报表
每日下班导入 Excel → 自动生成日报 → 报表可导出
📥 每日下班导入 Excel · 自动生成每日报表 支持 .xlsx / .xls / .csv
数据来源 每日下班导入 Excel 表格 导出格式：Excel 工作簿 本站未对接任何生产业务系统，报表由使用者导入的表格汇总生成

每日下班把当天通行明细 Excel 拖入下方，系统按日期自动汇总为一条日报（入区 / 出卡 / 重空 / 一线放行 / 边民申报 / 异常）； 同一天重复导入会覆盖更新，不会产生重复数据。也可直接导入已汇总好的日报表。

点击选择，或把 Excel / CSV 文件拖到这里
支持中文表头：日期 / 时间 / 方向 / 重空 / 放行结果 / 边民申报 / 异常
