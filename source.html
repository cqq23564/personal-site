本网站（「陈庆棋 · 个人主页」）是个人技术作品集与功能演示站点，用于展示数据看板、查询统计、参数配置、文件管理等 Web 功能的实现方式。

  • 本站与下述单位之间不存在隶属、授权、合作、背书或数据对接关系。
  • 本站内容不构成任何业务办理、通关、投资、法律或其他决策依据。

二、站内业务数据说明

数据看板、在场车辆、卡口记录、核放记录、文件台账、操作日志、留言等模块中出现的车牌号码、单证编号、企业名称、人名、数量、金额与时间， 均为本站自行构造的演示用示意数据，仅用于展示功能，不对应任何真实车辆、货物、申报单、企业或人员。

每日报表模块采用「每日下班导入 Excel 表格」的离线方式：由使用者在每日下班后手动导入当天的 Excel / CSV 表格， 本站自动识别两类格式——已汇总报表（如 B 卡报表，直接读取表内「货物名称 / 车数 / 重量」列组与车辆验放合计） 与逐车明细（按日期汇总为一条日报）；两者均按统计日期写入日报并支持导出，解析不出有效数值时不会写入全 0 日报。 该模块不自动从任何外部系统取数；导入内容完全由使用者提供并自行负责， 本站不校验、不背书其真实性，也不将其回传至任何第三方。

使用者还可上传自己的报表模板（如 B 卡报表）：本站仅解析模板中「货物名称 / 车数 / 重量」的列结构与合计行， 并自动识别导入明细里的货物名称列，按货物名称归类统计（车数 = 明细行数，重量 = 毛重千克 ÷ 1000 = 吨）， 再填回模板格式导出。模板文件与统计结果保存在本站云端账号下，供本人下次继续使用；模板与明细的具体内容均由使用者上传，本站不预设、不抓取任何业务数据。

货物名称统一口径：同一货物的不同叫法在统计时归并为同一标准名称并合并车数与重量，例如 「白火龙果」「红心火龙果」「鲜火龙果」「火龙果（产地）」一律按「火龙果」计算。归并仅去除产地、保鲜状态、颜色品种等前缀修饰词， 并校验标准货物名词库，避免把「白砂糖」等不同货物误并；导出与面板均同时保留「合并来源（原始货名）」以便核对。

按日期持久化与面板展示：每次导入的日报汇总写入 site_reports，货物统计按表格中的统计日期归类， 整组写入本站云端账号下的 site_report_goods 表；同一天重复导入会覆盖更新，不会残留旧叫法的重复行。刷新页面、更换浏览器或设备登录后， 「每日报表 → 历史导入数据」面板、「数据看板 → 导入货物统计」面板与数据看板首屏 KPI（入区 / 出区车数、重量、统一口径货物品种）都会自动读回云端数据， 可按日期切换查看，并支持导出该日报表或删除该日数据。这些结果仅来自使用者导入的表格，本站不校验、不背书其真实性。

5 个卡口数据看板：数据看板已按 B卡 / 互市 / 出口 / 零公里 / 查验区拆分为 5 个独立页面。 由于各卡口「需要查询的数据及报表是不一样的」，目前仅 B卡看板接入了使用者导入的 Excel 数据；其余 4 个看板保持明确的空态， 不套用 B 卡的表头、工作表或统计口径，也不填入示意数字，页面仅列出接入该卡口所需提供的样例信息（卡口名称/编号、 数据文件的工作表清单与表头、目标报表模板或差异点、统计口径）。待使用者提供对应样例后再按卡口独立配置指标并展示， 在此之前这 4 个看板不代表任何真实或示意业务量。

滞留 72 小时中国出口重车专题：这是与 5 个卡口并列的独立业务专题，不是物理卡口，因此不并入卡口切换条。 由使用者在「滞留重车导入」页每日下班手动导入 Excel / CSV 清单，按统计日期整组写入本站云端账号下的 site_stranded_trucks 表； 导入器支持三类格式：① 清单式报表（首行标题「2026年10月8日中国车出口滞留72小时」，每行「车牌　重车　M月D日」，末行「合计：N车」，三列 / 空格 / Tab / 连写均可识别）； ② 逐车明细清单；③ 汇总统计表（后两类按中文表头别名识别，不要求固定列位置）。 导入清单式报表时，系统在预览与专题看板中按原版式自动生成同款报表（标题 / 车牌 / 车型 / 入场日期 / 合计）， 并核对末行合计车数与实际识别行数；报表可导出为 CSV（Excel 可直接打开），页面上的浅色序号仅供核对、导出时不含。

清单式台账的统计口径：标题已声明「滞留 72 小时」，因此每行按 1 辆计入滞留车辆与达阈值车辆； 统计日期取自标题，国籍 / 方向取自标题文字（中国车 / 出口）。明细仅给出「M月D日」入场日期， 没有年份与时刻，不足以可靠推算精确滞留小时数，故本站不计算、不展示、不编造时长； 最长 / 平均滞留与时长分布在该模式下保持空态，改为展示重车 / 空车、明细条数、归档批次与入场日期分布等可核对指标。 若入场月日晚于统计日期（可能跨年或标题笔误），预览会给出提示，但不改写原文、不推算时长。 需要精确时长时请改用带「滞留时长(h)」列的标准台账模板导入。 预警阈值由参数 stranded.threshold.hours（默认 72 小时）控制，可在参数管理中修改。 未导入真实数据前所有指标显示「—」并保留空态，不预置示意数字、不套用其它卡口口径。

  • 本站未与「边境贸易（浦寨）慧眼智控嵌入式管理平台」或任何生产业务系统建立接口、账号、凭证或数据同步关系。
  • 站内不包含、也不展示海关监管数据、商业秘密、个人敏感信息或其他未公开数据；使用者若导入含上述内容的表格，应自行完成脱敏与合规审查。
  • 页面标注的「实时」「最后更新」等字样，仅指本站演示数据在浏览器中的刷新与联动，不代表对接了外部实时数据源。

导入数据的存档与恢复：每日报表、货物统计与滞留台账在「按统计日期整组覆盖」或「手动删除批次」前，会由本站自动把该批次的旧数据完整写入云端 site_import_snapshots 表；覆盖前原本没有数据时也会留存一份空快照，以便撤销误导入。导入页提供「一键回滚」，且回滚前会再存档当前状态，因此回滚本身同样可以撤回；快照写入失败会阻断本次覆盖，避免出现「以为能恢复其实没有」的情况。管理员可在导入页导出全量备份 JSON（含账号资料，请自行妥善保管）。

快照与备份仅用于本站误操作恢复，不是异地容灾；使用者应自行定期下载归档，并自行负责导入内容的合规审查与脱敏。快照表按最小权限控制：登录用户可读，仅管理员可写入与回滚。

七、数据安全与导入质量

访问控制：本站业务数据存放在站点自有云端账号下，由数据库行级安全策略控制—— 仅「已审核激活且已分配数据角色」的账号可以读取，写入仅超级管理员可用。新注册账号默认「待审核」， 在管理员审核并分配「只读成员」等角色之前，不能读取或修改业务数据；页面会明确提示账号状态，不会用空白表格伪装成「没有数据」。 角色、审核状态与账号归属由数据库触发器保护，普通账号无法自行提权。

导入质量闸门：每日报表与滞留重车台账在导入预览阶段即做质量校验。 合计与明细不符、统计日期缺失、明细为空、车牌缺失、数值为负、日报数值全 0 等属于阻断项，修正源文件前禁止写入； 重复车牌、可疑车牌格式、入场日期晚于统计日期、单位疑似混用、重空车与总车数不勾稽等属于需确认项， 必须逐项核对并显式勾选后才能导入，异常内容照实保留、不自动改写原文。仅在提示层面说明的口径 （如清单明细无年份与时刻、不推算滞留时长）不影响导入。

操作留痕与可恢复性：云端写入自动记录操作人、操作对象、改前改后值与失败原因； 覆盖与删除前生成快照，可一键回滚，回滚本身亦可撤回。快照与业务数据位于同一云端账号内， 不是异地容灾，请定期下载全量备份归档。

传输与脚本边界：全站设置内容安全策略（CSP），并把云 SDK 锁定为固定版本 + SRI 完整性校验， 静态镜像另配安全响应头。CSP 目前为缓解型——为兼容站内既有内联脚本仍允许 'unsafe-inline'， 属于纵深防御措施，不等同于彻底消除所有注入风险。本站不加载第三方统计、广告或追踪脚本。

八、隐私、安全与备份说明

传输与访问：本站全站通过 HTTPS 访问，明文请求会跳转到 HTTPS，静态镜像另启用 HSTS 与安全响应头。 站内不加载明文资源；本页列出的公开报道出处为外部链接，其目标站点是否支持 HTTPS 由对方决定，点击后会离开本站。

隐私与表单：本站不以收集个人信息为目的，注册只需手机号或邮箱与一个显示名称（可用昵称）； 不收集身份证号、精确位置、通讯录等无关信息，不接第三方统计、广告或追踪脚本。表单提交前会统一净化输入， 导出表格时对可能触发公式执行的字段做防护。完整说明见 隐私政策 与 用户协议； 你自行导入的 Excel 内容由你负责授权与脱敏。

备份：覆盖与删除前自动留存快照，可一键回滚；云端数据每周自动全量导出到本地备份目录， 导入页也可随时手动导出。备份与业务数据位于同一云端账号，不是异地容灾。

浏览器兼容与收录：页面针对 Chrome、Edge、微信内置浏览器与 Safari 做了语法与样式降级， 并按移动视口做过排版验证；站内提供 robots.txt、sitemap.xml 与静态链接便于搜索引擎收录。 由脚本动态生成的菜单与看板数据不属于静态内容，爬虫只能看到页面骨架。
