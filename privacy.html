🔐 隐私政策

生效日期：2026-11-10 · 最近更新：2026-11-10
← 返回首页
本站是个人技术作品集与功能演示站点，不是商业运营平台。本政策用直白语言说明：本站会接触到哪些信息、为什么需要它们、如何保管，以及你可以怎样要求删除。 本站不以收集个人信息为目的，也不设置广告、用户画像或第三方统计追踪。

一、会收集哪些信息

只有当你主动注册、登录或使用管理功能时，才会产生以下信息，除此之外本站不主动采集：

  • 账号标识：手机号或邮箱地址（二选一，用于验证码登录与识别账号），以及登录会话由平台身份认证服务生成的必要标识。
  • 展示资料：显示名称 / 昵称（可以使用昵称，不要求填写真实姓名）、可选填的部门与头像。这些字段用于界面显示与权限标注，不是必填的实名信息。
  • 操作记录：登录后的模块、动作、时间、操作对象、改前改后值与失败原因，用于排查误操作与审计，不做行为分析或营销。
  • 你自行导入的业务数据：每日报表、货物名称、车数、重量、滞留车辆车牌等 Excel / CSV 内容。这些内容由使用者自行准备并上传，本站不主动从任何外部业务系统抓取，也不核验其是否包含个人信息；请在导入前自行确认已获得相应授权并做必要的脱敏。

二、明确不收集的信息

本站不收集、也不要求填写：身份证号、护照号、银行卡或支付信息、生物识别信息、精确地理位置、通讯录、相册权限、设备标识符、健康与宗教等敏感信息。

本站不接入第三方统计、广告、埋点或追踪脚本；云 SDK 与 Excel 解析库均从固定地址加载并做完整性校验。本站不面向未满 14 周岁的儿童提供服务，也不会有意收集其信息。

三、信息用途与不共享承诺

收集到的信息仅用于四类用途：① 识别账号并区分管理员 / 只读成员等权限；② 保存与展示你导入的报表数据；③ 生成覆盖前快照、支持一键回滚与定期备份；④ 记录操作日志以便排错。

不会出售、出租、交换或向第三方共享你的账号资料与导入数据，不用于广告投放、自动化决策或模型训练。除非法律法规另有明确要求，本站不会对外提供这些数据。

四、存储、传输与安全措施

  • 传输：全站通过 HTTPS 访问，明文 HTTP 请求会跳转到 HTTPS；静态镜像启用 HSTS。
  • 存储：数据保存在本站自有云端账号下，由数据库行级安全策略控制——仅已审核激活且分配数据角色的账号可读取，写入仅超级管理员可用；新注册账号默认待审核、无数据权限。
  • 防护：内容安全策略（CSP）、云 SDK 固定版本与 SRI 完整性校验、输出统一转义、参数化查询、导入内容净化与质量闸门、CSV 公式注入防护、注册与自助提权拦截。
  • 备份：覆盖 / 删除前自动留存快照，可一键回滚；另每周导出全量 JSON 备份到本地目录。备份文件包含账号资料，由站点维护者妥善保管，不提交到代码仓库、不对外发布。

需要说明的是：这些措施降低风险但不能保证绝对安全；快照与业务数据位于同一云端账号，不构成异地容灾。

五、保留期限与删除

账号资料在你停止使用并申请删除前保留；导入的报表按统计日期归档，重复导入会覆盖同日数据（覆盖前会留存快照）；操作日志与快照用于追溯误操作，由站点维护者定期清理。

你可以：在「个人中心」修改自己的展示资料；在导入页按日期删除自己导入的批次或回滚；要求管理员删除账号、留言与相关日志；在导入页导出自己导入的数据。需要删除或导出协助时，请通过下方联系方式提出。

六、Cookie 与本地存储

本站不使用第三方 Cookie。浏览器本地存储仅用于记住浅色 / 深色主题偏好（键名 site-theme）；登录会话由平台身份认证服务在其自身域下管理。清除浏览器数据即可移除主题偏好，不影响已归档的云端数据。

七、第三方链接与依赖

「数据来源与声明」页包含指向公开报道与政府网站的外部链接，这些站点有各自的隐私政策，本站对其内容不承担责任。静态镜像（Cloudflare Pages 域名）仅为纯静态副本，不含云功能与账号数据。云 SDK 脚本由固定 CDN 地址加载，页面不向该 CDN 提交你的表单内容。

八、政策变更与联系

本政策如有调整，会更新本页的「最近更新」日期。若你继续使用的是演示或自行导入的数据，调整不会改变这些数据的归属。

联系方式：页脚与「数据来源与声明」页展示的 contact@example.cn 是示例邮箱，正式对外提供服务前应替换为站点维护者的真实联系渠道；在此之前，请通过 WorkBuddy 任务对话向站点维护者提出隐私相关请求。相关条款另见 用户协议 与 数据来源与声明。
